## Patient Appointment System

A role-based patient appointment management system designed to streamline scheduling and improve accessibility for both patients and healthcare providers.

### Features
- Patients can book appointments without creating an account  
- Doctors and staff have secure login access  
- Staff can create, view, update, and delete appointments for assigned doctors  
- Admin can manage doctor records  
- Doctors can view schedules and update appointment status  
- Walk-in appointments are automatically assigned to the latest available schedule  
- Patients receive email/SMS reminders for upcoming appointments  

### Tech Stack
MongoDB, Express, React, Node.js, Redis
